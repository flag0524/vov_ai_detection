# tests.md — 단계별 검증 기준

> 각 Phase는 이 파일의 기준을 충족해야 완료로 인정한다. 기준 미달 시 해당 Phase를 재작업한다.

---

## Phase 0 — 기반 셋업

| 검증 항목 | 방법 | 합격 기준 |
| --- | --- | --- |
| FastAPI 헬스체크 | `GET /health` 응답 확인 | HTTP 200, `{"status":"ok"}` |
| PostgreSQL 연결 | DB 커넥션 + 스키마 테이블 존재 확인 | AIModel, Product, GenerationJob, Content 테이블 생성 |
| Redis/Queue 연결 | 더미 job enqueue → dequeue | job_id 반환 및 상태 조회 가능 |
| Object Storage | 더미 파일 업로드 → URL 반환 | 업로드 성공, 서명 URL 접근 가능 |

## Phase 1 — 상품 분석 & AI 모델 생성

| 검증 항목 | 방법 | 합격 기준 |
| --- | --- | --- |
| 상품 분석 | 패션 이미지 업로드 → 메타데이터 반환 | category, color, material 등 스키마 필드 추출 |
| Soul ID 학습 | `POST /ai/model/create` 호출 | `soul_reference_id` DB 저장 확인 |
| 모델 동일성 | 동일 model_id로 이미지 3장 생성 | 얼굴 임베딩 유사도 ≥ 0.85 (3장 간) |

---

## Phase 2 — 이미지 생성

| 검증 항목 | 방법 | 합격 기준 |
| --- | --- | --- |
| 프롬프트 자동 생성 | Agent 2 호출, 상품 메타 입력 | 완성된 영문 프롬프트 반환 |
| 이미지 생성 | `POST /ai/image/generate` 비동기 호출 | job 완료 후 이미지 URL 반환 |
| 상품 원본 유지율 | SSIM(원본 vs. 생성) | SSIM ≥ 0.80 |
| 재생성 큐 | 유지율 미달 케이스 시뮬레이션 | 자동 재생성 큐 진입 확인 |

---

## Phase 3 — 영상 생성

| 검증 항목 | 방법 | 합격 기준 |
| --- | --- | --- |
| 영상 생성 | `POST /ai/video/generate` 호출 | 5~15초, 9:16 비율 영상 URL 반환 |
| 얼굴 일관성 | 영상 키프레임 추출 → 얼굴 임베딩 비교 | 프레임 간 유사도 ≥ 0.80 |
| 배경 왜곡 | 시각 검사 (자동 점수 보조) | 명백한 배경 왜곡 없음 |

## Phase 4 — SNS 콘텐츠

## Phase 5 — 프론트엔드 & E2E

| 검증 항목 | 방법 | 합격 기준 |
| --- | --- | --- |
| 업로드 UI | 브라우저에서 상품 이미지 업로드 | product_id 반환 |
| 생성 요청 및 폴링 | 생성 버튼 클릭 → 상태 표시 → 완료 | 이미지·영상·카피 화면에 표시 |
| E2E 파이프라인 | 상품 1건 업로드 → 전체 산출물 자동 생성 | 화보·릴스·카피 모두 산출 (10분 이내) |

## Phase 6 — 품질 자동화

| 검증 항목 | 방법 | 합격 기준 |
| --- | --- | --- |
| 자동 평가 루프 | 생성 완료 후 자동 점수 계산 | Image/Video Quality Score 자동 기록 |
| 재생성 루프 | 기준 미달 케이스 주입 | 재생성 큐 자동 진입 → 재시도 후 기준 통과 |
| 처리 시간 측정 | E2E 타이밍 로그 | 상품 1건 → 전체 산출물 시간 측정값 기록 |

## 게이트 (모든 Phase 공통)

다음 두 조건은 Phase 1 이후 모든 생성 단계에서 반드시 통과해야 한다.

1. 상품 원본 유지율 (SSIM ≥ 0.80)
2. 모델 얼굴 동일성 점수 (임베딩 유사도 ≥ 0.85)

미달 산출물은 배포하지 않는다.
