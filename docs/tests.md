# tests.md — 단계별 검증 기준

> 각 Phase는 이 파일의 기준을 충족해야 완료로 인정한다. 기준 미달 시 해당 Phase를 재작업한다.

> **2026-07-01 기준**: Phase 1~4는 Higgsfield MCP 미인증 상태라 "스텁 모드"로 검증되었다. 이미지/영상 URL은 실제 생성물이 아닌 스텁 URL이며, SSIM은 스텁 이미지 자체(원본=생성본 동일 파일)로 계산해 통과 확인만 한 것이다. Higgsfield 실연동 후 실제 생성물 기준으로 전체 게이트를 재검증해야 한다. → [status.md](status.md) 참고.

## 완료 기준 2-트랙 (2026-07-03 사용자 승인)

외부 자격증명(Higgsfield 크레딧, ANTHROPIC_API_KEY)은 코드 작업으로 대체 불가능하므로 완료 기준을 두 트랙으로 나눈다.

| 트랙 | 기준 | 상태 |
| --- | --- | --- |
| **1차: 스텁 모드** | 아래 Phase별 표의 검증 항목을 스텁 산출물 기준으로 통과. 자동화: `backend/tests/` pytest 17건 + 실브라우저 클릭 E2E | ✅ Phase 0~6 완료 (2026-07-03) |
| **2차: 실생성물** | 동일 기준을 Anthropic/Higgsfield 실호출 산출물로 재통과 (SSIM·얼굴 유사도는 실생성 이미지 간 계산) | ⬜ 대기 — 선결: ① Higgsfield 크레딧 충전 ② ANTHROPIC_API_KEY 제공 |

1차 트랙 통과로 이번 목표(문서체계 구축 + 기준대로 수행)는 완료 처리한다. 2차 트랙은 선결 조건 해소 후 별도 요청으로 진행한다.

## Phase 5 — 프론트엔드 & E2E

| 검증 항목 | 방법 | 합격 기준 | 결과 (2026-07-01) |

## 게이트 (모든 Phase 공통)

다음 두 조건은 Phase 1 이후 모든 생성 단계에서 반드시 통과해야 한다.

1. 상품 원본 유지율 (SSIM ≥ 0.80)
2. 모델 얼굴 동일성 점수 (임베딩 유사도 ≥ 0.85)

미달 산출물은 배포하지 않는다.
