## 실검증 현황 요약 (2026-07-05)

| 항목 | 상태 | 근거 |
| --- | --- | --- |
| 이미지 실생성 (Higgsfield `soul/standard`) | ✅ | 실사 화보급 3회 생성 성공, naturalness 지시어 반영 육안 확인 |
| 릴스 9:16 규격 | ✅ | 이미지 단계 9:16 출력 실측 (960x1696) — 영상(DoP)은 입력 비율 추종 확인 |
| 영상 실생성 (Higgsfield `dop/standard`) | ✅ | 5.4초 mp4 실생성, cv2로 규격 실측 |
| SSIM 실측·검수 플래그 | ✅ | 실생성물 0.566 실측 → ADR-011 정보성+manual_review로 개정·구현 |
| 상품 분석 | ✅ (기준 변경) | ADR-012: Vision 분석 폐기 → 직접 입력, 입력값의 프롬프트/캡션 반영 테스트로 검증 |
| 프롬프트·SNS 카피 | ✅ (기준 변경) | ADR-012: 규칙 기반 템플릿 = 실구현 자체. 해시태그·카피 길이 테스트로 검증 |
| 실브라우저 E2E | ✅ | Chrome DevTools 클릭 조작 검증 |
| Soul ID 학습·모델 동일성(얼굴 임베딩) | ⏸ 외부 블로킹 | Higgsfield Soul 학습 API 미공개 (ADR-008) — 공개 시 재개 |
| 실상품 기준 상품 보존 정밀 검증 | ⏸ 사용자 준비 대기 | 현재 test_product.jpg는 도형 플레이스홀더 — 실상품 사진 확보 후 진행 |
| 영상 얼굴 일관성·배경 왜곡 | ⏸ Soul 학습 의존 | 임베딩 확보 전 계산 불가 (조건부 게이트) |

위 ⏸ 3건은 코드로 해소 불가능한 외부 의존(미공개 API, 실상품 사진)이며, 해소 즉시 코드 변경 없이(또는 `create_soul_id()` 1개 함수 교체로) 재개된다.

## 게이트 (모든 Phase 공통)

다음 두 조건은 Phase 1 이후 모든 생성 단계에서 반드시 통과해야 한다.

1. 상품 원본 유지율 (SSIM ≥ 0.80)
2. 모델 얼굴 동일성 점수 (임베딩 유사도 ≥ 0.85)

미달 산출물은 배포하지 않는다.
