# PRD — JBLANC AI Fashion Marketing Automation System

> Product Requirements Document
> 버전 1.0 · 작성일 2026-06-30

---

## 1. 개요

제이블랑(JBLANC) 자사몰의 패션 상품 이미지를 입력받아, AI 모델·이미지·영상 콘텐츠를 자동 생성하고 인스타그램 릴스 및 광고 콘텐츠까지 제작하는 마케팅 자동화 플랫폼이다.

핵심 가치는 실제 촬영 스튜디오 없이 글로벌 패션 브랜드 수준의 화보와 영상을 만들어, 상품 등록만으로 SNS 콘텐츠를 자동 생산하는 것이다.

## 2. 문제 정의

- 신상품마다 모델 섭외·스튜디오 촬영·후보정에 높은 비용과 시간이 든다.
- SNS 채널(릴스, 쇼츠, 피드)을 빠르게 채우기 위한 콘텐츠 공급이 부족하다.
- 브랜드 화보의 톤앤매너와 모델 일관성을 매번 유지하기 어렵다.

## 3. 목표 (Goals)

| 구분 | 목표 |
| --- | --- |
| 비용 | 촬영 스튜디오 없이 화보·영상 제작 |
| 속도 | 상품 등록 → SNS 콘텐츠 자동 생성 |
| 품질 | 글로벌 패션 브랜드 광고 수준 |
| 일관성 | 동일 AI 모델의 얼굴·체형·스타일 유지 |
| 보존 | 상품 원본 디자인·색상·패턴 변경 금지 |

### Non-Goals (1차 범위 제외)

- 실제 인스타그램 자동 게시(API 직접 발행)는 예약·등록 준비까지만 지원하고 발행 자동화는 후속 단계로 둔다.
- 다국어 카피 자동화는 한국어 우선, 이후 확장한다.

## 4. 사용자 (Personas)

- **브랜드 마케터** — 상품을 업로드하고 콘텐츠를 받아 채널에 배포한다.
- **MD/운영자** — 신상품 등록 직후 콘텐츠가 준비되기를 기대한다.
- **디자이너/검수자** — 상품 원본 유지율과 브랜드 적합도를 확인한다.

## 5. 핵심 기능 요구사항

### 5.1 AI 모델 생성 시스템

한 번 생성한 모델을 지속적으로 동일 인물로 유지한다.

- 얼굴 Identity, 헤어스타일, 체형, 피부톤, 패션 스타일 유지.
- 다양한 포즈 생성 가능.

모델 ID 예시는 `MODEL_JBLANC_001`이며 속성 스키마는 다음과 같다.

```json
{
  "soul_reference_id": "",
  "body_style": "",
  "hair_style": "",
  "age": "",
  "mood": "",
  "fashion_style": ""
}
```

모델 얼굴 일관성은 Higgsfield Soul ID(Soul Character)로 구현한다. 모델당 1회 학습한 `soul_reference_id`를 저장하고, 모든 이미지·영상은 동일 모델 ID(= 동일 Soul ID)를 기반으로 생성한다.

### 5.2 상품 기반 AI 이미지 생성

사용자가 상품 이미지(원피스, 자켓, 코트, 가방 등)를 업로드하면 AI가 특징을 자동 분석한다.

추출 스키마.

```json
{
  "product_name": "",
  "category": "",
  "color": "",
  "material": "",
  "silhouette": "",
  "season": "",
  "style": "",
  "target_customer": ""
}
```

분석 결과로 화보 프롬프트를 자동 생성한다(예: 럭셔리 여성 패션 화보, 20대 후반 AI 모델, 제이블랑 감성, 상품 원본 유지, 강남 부티크 배경, 자연광, 매거진 스타일, 8K realistic).

### 5.3 상품 원본 유지 기능

다음 항목은 절대 변경 금지다.

- 옷 디자인, 패턴, 색상, 로고, 소재 표현, 핏.

상품 이미지를 Higgsfield의 reference 제어(product-photoshoot / image-to-image reference)로 적용해 원본을 보존하고, 생성 후 상품 영역 유지율을 자체 검수한다.

### 5.4 AI 영상 생성 시스템

생성 이미지를 입력받아 5~15초 패션 영상을 출력한다.

- 모델 움직임: 자연스러운 걷기, 옷자락·머리카락 움직임, 손동작, 카메라 워킹.
- 배경: 패션 매장, 럭셔리 호텔, 서울 거리, 카페, 스튜디오.
- 카메라: Cinematic movement, Dolly shot, Slow motion, Depth of field.
- 품질: 실제 패션 브랜드 광고 영상 수준.

### 5.5 인스타그램 콘텐츠 자동 생성

- 이미지: 피드, 제품 소개, 화보.
- 영상: 릴스, 쇼츠, 광고 영상.
- 텍스트: 게시글 문구, 해시태그, 광고 카피.

예시 문구는 "오늘의 무드를 완성하는 제이블랑 신상 컬렉션"이며 해시태그는 #제이블랑 #여성패션 #데일리룩 #오피스룩 형태다.

### 5.6 브랜드 스타일 학습

VOV 등 참조 데이터의 색감, 모델 포즈, 촬영 구도, 배경, 조명, 패션 감성을 분석해 제이블랑 전용 스타일(JBLANC STYLE MODEL)을 생성한다.

## 6. 사용자 플로우

```
상품 이미지 업로드
  → 상품 분석 AI
  → 프롬프트 자동 생성
  → AI 모델 선택
  → 패션 이미지 생성
  → 영상 변환
  → 릴스 콘텐츠 생성
  → 인스타 업로드 관리
```

## 7. 품질 검증 기준

| 평가 | 검증 항목 |
| --- | --- |
| Image Quality Score | 얼굴 동일성, 상품 유지율, 자연스러움, 브랜드 적합도 |
| Video Quality Score | 움직임 자연스러움, 배경 왜곡, 얼굴 변화 여부 |

## 8. 성공 지표 (KPI)

- 상품 1건 업로드 → 화보·릴스·카피 자동 산출까지의 처리 시간.
- 상품 원본 유지율(검수 통과 비율).
- 모델 얼굴 동일성 점수.
- 콘텐츠 채택률(생성물 중 실제 배포된 비율).

## 9. 최종 목표

사용자가 제이블랑 상품 이미지를 업로드하면 AI 모델 선택, 화보 이미지 생성, 릴스 영상 제작, SNS 광고 문구 생성, 인스타그램 콘텐츠 등록 준비까지 자동 수행하는 "JBLANC AI Fashion Creator Platform"을 구축한다.
