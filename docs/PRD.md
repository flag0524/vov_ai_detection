# PRD — 제이블랑(JBLANC) AI Fashion Content Automation System

- 문서 버전: v1.1
- 작성일: 2026-07-02
- 변경 이력: v1.1 — **자연스러운 동작·표정(Naturalness) 요구사항** 추가 (FR-7, 품질 기준 강화)

---

## 1. 개요

제이블랑 자사몰의 패션 상품 이미지를 입력받아 AI 이미지 생성 및 AI 영상 생성 기술로
인스타그램 홍보 콘텐츠(피드 이미지, 릴스 영상, 스토리)를 자동 제작하는 시스템.

**벤치마크:** 패션 브랜드 VOV(보브) 인스타그램 수준의 고품질 AI 콘텐츠.

## 2. 목표 및 성공 기준

| 목표 | 성공 기준 |
|---|---|
| AI 모델 얼굴 일관성 | Face embedding similarity ≥ 0.85, 콘텐츠 간 동일 인물 인식률 95% 이상 |
| 자연스러운 동작·표정 | 부자연스러운 동작/표정 검출률 5% 미만 (내부 QA 기준) |
| 화보 품질 | 실제 패션 화보 수준, "AI 티" 나는 결과물 재생성률 10% 미만 |
| 제작 자동화 | 상품 업로드 → 인스타 콘텐츠 출력까지 무인 파이프라인 |
| 콘텐츠 산출 | 상품 1건당 피드 이미지, 릴스 영상, 스토리, 캡션/해시태그 자동 생성 |

## 3. 타겟 사용자

- 제이블랑 마케팅/콘텐츠 담당자 (상품 이미지 업로드 후 결과물 검수·배포)
- 최종 소비자: 제이블랑 인스타그램 팔로워 및 광고 노출 고객

## 4. 핵심 기능 요구사항

### FR-1. 상품 기반 AI 콘텐츠 생성
- 입력: 상품 이미지, 상품명, 브랜드/시즌/스타일 정보, 타겟 고객
- AI 자동 분석: 의류 종류, 소재, 색상, 디자인 특징, 착용 스타일, 어울리는 모델, 배경 컨셉
- 출력: 패션 화보 이미지, 인스타 광고 이미지, 릴스 영상용 프롬프트, 광고 문구

### FR-2. AI 모델 ID 시스템 (얼굴 고정)
- 생성된 AI 모델은 고유 ID 보유 (예: `JBLANC_MODEL_001`)
- 저장 정보: 얼굴 특징, 헤어스타일, 체형, 피부톤, 분위기, 포즈 스타일
- 신규 상품 생성 시 기존 모델 ID 호출 → "동일 모델이 다른 옷을 착용"
- Negative Prompt 필수 적용: different face, changed identity, different person, inconsistent face

### FR-3. 이미지 생성 파이프라인
상품 업로드 → 상품 분석 AI → 패션 컨셉 생성 → Prompt Engineering → AI Image Generation → 품질 검증 → Instagram Content Output

### FR-4. AI 영상 생성
- 얼굴 유지, 자연스러운 걷기, 자연스러운 손동작, 옷 움직임 표현, 카메라 이동, 배경 자연스러운 변화
- VOV 인스타그램 스타일의 시네마틱 패션 영상

### FR-5. 인스타그램 콘텐츠 자동 제작
- Feed 이미지 1080x1350, Reel 영상 1080x1920, Story 1080x1920
- Caption, Hashtag, Product description 자동 생성

### FR-6. 브랜드 스타일 학습
- VOV 공식 인스타그램 스타일 분석: 색감, 모델 포즈, 배경, 영상 템포, 카메라 무빙, 광고 문구
- JBLANC 브랜드 스타일로 재해석

### FR-7. 자연스러운 동작·표정 (Naturalness) — 신규
생성되는 모든 이미지·영상에서 모델의 동작과 표정이 실제 인물처럼 자연스러워야 한다.

**이미지 요구사항**
- 표정: 경직되거나 과장되지 않은 자연스러운 표정 (은은한 미소, 자연스러운 시선 처리, 자연스러운 눈 깜빡임 상태)
- 포즈: 해부학적으로 올바른 관절 각도, 자연스러운 무게중심, 실제 화보 포즈 기반
- 손: 손가락 개수/형태 정확, 부자연스러운 손 모양 금지
- 시선: 카메라 또는 컨셉에 맞는 자연스러운 시선 방향

**영상 요구사항**
- 걷기: 실제 워킹 속도·보폭·팔 스윙, 로봇 같은 움직임 금지
- 표정 변화: 프레임 간 표정이 부드럽게 연결, 표정 급변·얼굴 뭉개짐(morphing) 금지
- 손동작: 자연스러운 손 제스처, 손가락 왜곡 없는 움직임
- 신체 물리: 머리카락·옷의 물리 기반 움직임, 관절 꺾임 오류 금지
- 전환: 배경·카메라 이동 시 인물 동작의 연속성 유지

**Negative Prompt 추가 항목**
stiff pose, unnatural facial expression, frozen face, awkward smile, robotic movement,
jerky motion, unnatural gait, distorted fingers, broken joints, uncanny valley,
expression morphing, twitching face

**검증 기준**
- 생성 결과물에 대한 Motion/Expression QA 단계 필수 (자동 + 육안 검수)
- 부자연스러운 동작·표정 검출 시 자동 재생성

## 5. 비기능 요구사항

- 이미지 1장 생성 소요 ≤ 2분, 영상 1건 ≤ 10분 (외부 API 기준)
- 생성 이력·모델 정보·프롬프트 전체 DB 저장 (재현 가능성)
- 실패 시 자동 재시도 및 오류 알림

## 6. 개발 단계 (Phase)

1. Phase 1: 상품 업로드 → AI 분석 → 프롬프트 생성
2. Phase 2: AI 모델 고정 시스템 구축
3. Phase 3: 이미지 생성 (+ 표정·포즈 자연스러움 검증)
4. Phase 4: 영상 생성 (+ 동작 자연스러움 검증)
5. Phase 5: Instagram 자동 배포

## 7. 범위 제외 (Out of Scope)

- 인스타그램 외 채널(유튜브, 틱톡) 배포
- 실제 모델 촬영 대체가 아닌 병행 운영
- 사용자(고객) 대상 셀프 생성 서비스
