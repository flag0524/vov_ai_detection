# goal.md — JBLANC AI Fashion Marketing Automation System

> 이 파일은 프로젝트의 최종 목표와 성공 기준을 정의한다. 작업 전 반드시 이 파일을 읽고 목표와 정렬 상태를 유지할 것.

---

## 최종 목표

사용자가 제이블랑(JBLANC) 패션 상품 이미지를 업로드하면 **AI 모델 화보 이미지 → 릴스 영상 → SNS 카피**를 자동 생성하는 마케팅 자동화 플랫폼 구축.

## 핵심 불변 제약

1. **상품 원본 절대 변경 금지** — 디자인·패턴·색상·로고·소재·핏.
2. **모델 동일성 유지** — 모든 생성물에 동일 Soul ID 주입.
3. 위 두 조건을 통과하지 못한 산출물은 배포하지 않는다.

## 성공 기준 (KPI)

| KPI | 측정 방법 |
| --- | --- |
| 처리 시간 | 상품 1건 업로드 → 화보·릴스·카피 자동 산출까지 |
| 상품 원본 유지율 | SSIM / 임베딩 유사도 (기준 미달 → 재생성) |
| 모델 얼굴 동일성 점수 | 검수용 얼굴 임베딩 유사도 |
| 콘텐츠 채택률 | 생성물 중 실제 배포된 비율 |

## 범위 (Non-Goals)

- 인스타그램 자동 발행 (예약·등록 준비까지만)
- 다국어 카피 (한국어 우선, 이후 확장)
- 자체 GPU 추론 인프라 (전부 Higgsfield MCP 사용)
